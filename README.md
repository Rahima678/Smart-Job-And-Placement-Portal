# Smart-Job-And-Placement-Portal
 1. Introduction
Smart Job & Placement Portal is a web-based application developed using MERN Stack. It connects students, recruiters, and placement officers on a single platform to manage job opportunities and placement activities.
 
 2. Problem Statement
Traditional placement processes depend on spreadsheets, emails, and WhatsApp groups. This makes job management difficult and time-consuming. The portal provides a centralized solution.

3. Objectives
- To connect students and recruiters.
- To simplify the placement process.
- To check student eligibility automatically.
- To recommend jobs based on skills.
- To track job applications.

4. User Roles
The system has three main users:
- **Student:** Creates profiles, uploads resumes, searches and applies for jobs.
- **Recruiter:** Posts jobs and manages student applications.
- **Admin:** Manages students, approves jobs, and monitors placements.

5. System Architecture
The system consists of three main layers: React.js for frontend, Node.js and Express.js for backend, and MongoDB for database management.

 6. Technology Stack
The project uses React.js, Node.js, Express.js, MongoDB, Mongoose, JWT, Bcrypt, Tailwind CSS, Postman, and GitHub.

7. Database Design
The database contains three main collections:
- **User:** Stores student, recruiter, and admin details.
- **Job:** Stores job descriptions and requirements.
- **Application:** Stores student applications and their status.

 8. Smart Features
- Automatic eligibility checking.
- Skill-based job recommendations.
- Job matching percentage.
- Duplicate application prevention.
- Automatic deadline management.

9. REST API
REST APIs are used for communication between frontend and backend. They handle user login, job listings, job applications, and application status updates.

 10. Workflow and Future Scope
Recruiters post jobs, admins approve them, eligible students apply, and recruiters shortlist or select candidates.

Future improvements include AI-based resume parsing, interview scheduling, email notifications, and a mobile application.

 11. Conclusion
Smart Job & Placement Portal makes the recruitment process easier, faster, and more organized by connecting students, recruiters, and placement officers through a single platform.
